# Vulture / Refugee live diagnostics — 2026-09-07

Enabled for the next test via `exilerefugee.salvageExpeditions.diagnostics` in
`data/config/exiles/director_config.json`. Restart the game after changing this flag.
No new campaign is required for this diagnostic addition.

Stay in the battle system from before combat until several campaign days after the
Refugees finish collecting. Note the system and approximate campaign date. Preserve
`starsector-core/starsector.log` before starting another game session.

Search for `SALVAGE_DIAG`. The startup `ENABLED` line confirms instrumentation is active.
Half-day `SAMPLE` observations cover the player's current star system. Dispatch,
target selection, and before/after collection events cover Refugees throughout the sector.
Shared target IDs and campaign timestamps correlate these events. Battle fields include
scavenged/fading state and base salvage XP/density; Nex cached demand and expiry,
selected spawn system, current spawn-rate multiplier, and raid action state are recorded.
The rate belongs to Nex's selected system, which may differ from the observed system.

These are passive samples, not hooks into actual Nex evaluations. Keep Nex's own
`Trying vulture fleet`, `No scavenge target found`, and `Spawned` lines when analyzing.
The 2026-09-08 fix removes reflection, which Starsector prohibits in loose scripts.
Nex's selected system and rate are read through its vanilla DisposableFleetManager base
class. Exact Nex target lists and uncached scores are no longer queried. Nex's own
hostile-rejection messages are no longer generated by diagnostic sampling.
First appearance in a sample means first observed, not exact creation time. The logger
does not call demand/update/advance methods, alter the cache, or delay Refugees.
State used to suppress unchanged samples is transient and rebuilt after loading a save.

Validation: Janino compilation of diagnostic and both calling scripts; shared-code
compatibility harness verifies snapshot output and unchanged Nex cache value/expiry.
Full campaign scheduling and live logging still require the in-game test.
